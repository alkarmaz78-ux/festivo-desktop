FESTIVO — Windows-приложение с отдельными окнами

ЧТО ПОЛУЧИТСЯ
- Установщик Windows FESTIVO-Setup-1.0.0.exe.
- Ярлык на рабочем столе и в меню «Пуск».
- Основное окно для панели ведущего.
- Дополнительные окна FESTIVO для экранов, которые можно перетащить на телевизор или второй монитор.

КАК СОБРАТЬ УСТАНОВЩИК
1. Сборка автоматически запускается в GitHub Actions после добавления файлов в репозиторий.
2. Открой вкладку Actions в https://github.com/alkarmaz78-ux/festivo-desktop/actions
3. Открой последний запуск «Build FESTIVO Windows installer».
4. Дождись зелёной галочки, открой запуск и скачай артефакт FESTIVO-Windows-Installer.
5. Распакуй скачанный ZIP. Внутри будет файл FESTIVO-Setup-1.0.0.exe.
6. Запусти EXE и установи приложение.

Node.js на своём компьютере устанавливать не нужно: сборка выполняется на временном Windows-компьютере GitHub Actions.

КАК ПОЛЬЗОВАТЬСЯ
1. Запусти FESTIVO с ярлыка и войди в аккаунт.
2. Открой мероприятие в панели ведущего.
3. Нажми ссылку/кнопку экрана гостей. Ссылка, открывающая новое окно сайта FESTIVO, будет открыта в отдельном окне приложения.
4. Перетащи окно экрана гостей на телевизор/второй монитор и разверни его на весь экран.

Важно:
- Приложение открывает сайт https://festivo.s-afamilyevent.workers.dev/ и требует интернет.
- Этот проект не изменяет данные мероприятий или настройки Supabase.
- Установщик ещё должен быть успешно собран в Actions, прежде чем его можно скачать.
